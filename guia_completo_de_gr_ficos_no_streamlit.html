Pandas Melt

Transformando Formato Largo em Longo

O Plotly Express funciona melhor com DataFrames no formato "Longo" (Tidy Data), onde cada coluna representa uma variável e cada linha uma observação. Use pd.melt() para reorganizar colunas de categorias. 

import pandas as pd

# DataFrame em formato Largo
df_largo = pd.DataFrame({
    'UF': ['SP', 'RJ', 'MG'],
    'Homens': [12.5, 11.2, 10.8],
    'Mulheres': [18.4, 17.1, 16.5]
})

# Converte para formato Longo
df_longo = df_largo.melt(
    id_vars=['UF'],
    value_vars=['Homens', 'Mulheres'],
    var_name='Gênero',
    value_name='Horas'
)
Streamlit Integration

Exibição Fluida e Cache

Para otimizar a performance da sua aplicação e garantir responsividade total no Streamlit, utilize o parâmetro use_container_width=True e decore funções de carregamento de dados com @st.cache_data. 

import streamlit as st
import plotly.express as px

@st.cache_data
def carregar_dados():
    return pd.read_csv("dados.csv")

df = carregar_dados()

fig = px.bar(df, x="UF", y="Horas", color="Gênero")

# Garante responsividade perfeita
st.plotly_chart(fig, use_container_width=True)
